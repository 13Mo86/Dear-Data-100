Behind the Bar - Dear Data 100
Overview:
This project explores the drinks I prepare during my bartending shifts and investigates patterns in drink popularity, preparation difficaulty, and workload.
RQ:
How do drink preferences, preparation difficulty, and  workload vary across my bartending shifts?
Data Collection:
the date of each shift
the type of drinks 
the quantity of each drink
difficulty 1-5
busyness 1-5
Visualisation:
I will use Processing to create a creative visual repredentation of at least 100 drink observations. 
Project Status:
Initial setup and data collection preparation.
